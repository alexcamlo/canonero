# Cañonero

Created in [T3 Code](https://t3.codes).

The truck is always set up for sand, with fixed sand tyres and automatic short gearing. Just steer, accelerate and brake/reverse; there are no tyre-pressure or high/low-range controls. Momentum and route choice still matter on soft sand and steep dunes.

Radio starts off. Tap **Radio** (or press R) to play, advance through the six tracks, then turn it off. **R** toggles playback; **N** skips to the next track (and turns it on). Tracks advance automatically when finished. Hiding the tab pauses the radio; tap Radio or press R to resume.
